## 🖥️ 프로젝트 소개
인터넷에 산개해 있는 태양광과 관련되 데이터를 한 곳에 모아 지도에 적용시켜 후에 태양광 발전시스템을 설치할 위치를 특정하는 것에 도움을 줄 수 있는 프로그램

#### 프로젝트 구동법<br>

* 배포되어 있는 사이트로 들어가 오른쪽 위에 layer를 사용하여 원하는 형식의 데이터를 결정한다.
* 그 후 원하는 지역에 마우스 커서를 가져가면 데이터 값이 출력된다.
